# Mapa de documentación

Esta carpeta describe el producto que se implementa. Ante una contradicción, manda el documento más específico de la primera sección.

## Documentos vigentes

1. [`PRODUCT_REQUIREMENTS.md`](PRODUCT_REQUIREMENTS.md): alcance, flujo, comportamiento y criterios de aceptación.
2. [`PRIMARY_CANVAS.md`](PRIMARY_CANVAS.md): composición de Cocina y reglas para que el lienzo principal cambie según el paso.
3. [`VISUAL_LANGUAGE.md`](VISUAL_LANGUAGE.md): color, tipografía, bordes, sombras y significado visual.
4. [`INTERACTION_AND_MOTION.md`](INTERACTION_AND_MOTION.md): gestos, relojes, háptica y animaciones.
5. [`ARCHITECTURE.md`](ARCHITECTURE.md): límites técnicos, estado, persistencia e importación.
6. [`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md): orden de trabajo, alcance de cada entrega y verificación.
7. [`CHATGPT_HANDOFF.md`](CHATGPT_HANDOFF.md): traspaso desde una conversación a un archivo Mise.
8. [`ANDROID.md`](ANDROID.md): instalación y capacidades nativas.
9. [`RELEASE_0.3_PLAN.md`](RELEASE_0.3_PLAN.md): alcance cerrado, orden y aceptación de la próxima entrega.
10. [`RELEASE_0.3.1_PLAN.md`](RELEASE_0.3.1_PLAN.md): corrección visual de ingredientes y acceso al prompt maestro.
11. [`RELEASE_0.4_PLAN.md`](RELEASE_0.4_PLAN.md): candidata para pruebas cotidianas.
12. [`PROMPT_KIT.md`](PROMPT_KIT.md): perfiles, adaptación de chats y versionado del kit.
13. [`SECURITY_INPUTS.md`](SECURITY_INPUTS.md): tratamiento inicial de archivos no confiables.
14. [`PRODUCT_BRIEF.md`](PRODUCT_BRIEF.md): ficha pública, propuesta, audiencia y sostenibilidad.

## Evidencia y decisiones

- [`RESEARCH_NOTES.md`](RESEARCH_NOTES.md): recetas reales y problemas observados.
- [`DESIGN_REVIEW_2026-09.md`](DESIGN_REVIEW_2026-09.md): registro de decisiones aprobadas.
- [`DESIGN_DIRECTIONS.md`](DESIGN_DIRECTIONS.md): alternativas históricas; no es una especificación vigente.

## Regla de mantenimiento

Una decisión de producto se escribe primero en Requerimientos. Su traducción visual o técnica se agrega después al documento específico. No se copian párrafos completos entre archivos: cada documento enlaza el concepto y describe solo su parte.
