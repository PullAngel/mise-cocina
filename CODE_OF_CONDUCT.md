# Código de conducta

Mise busca una comunidad paciente, curiosa y útil. Esperamos conversaciones respetuosas, críticas concretas y apertura a que otras personas cocinen, aprendan o usen tecnología de maneras distintas.

No se toleran hostigamiento, discriminación, ataques personales, publicación de datos privados ni contenido deliberadamente dañino. El desacuerdo técnico es bienvenido cuando se centra en el trabajo y aporta evidencia o una alternativa.

Los incidentes pueden reportarse de forma privada mediante las opciones indicadas en [SECURITY.md](SECURITY.md). Quienes mantengan el proyecto podrán editar o retirar contenido y limitar la participación cuando sea necesario para proteger a la comunidad.
